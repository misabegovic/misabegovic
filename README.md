### Hi, I'm Muhamed 👋

I've spent ten years taking products from first idea to production and leading the teams that build them. Right now I'm building tools that make AI-assisted development hold up in real codebases. Rubyist since 2016.

#### Projects

- **[tabula](https://github.com/misabegovic/enola-guides/blob/main/guides/13-tabula.md)** *(in private development)*: a memory layer for coding agents. Pages a team writes about what the code should be and why, checked against the code, so every agent starts from what was decided.
- **[taha](https://github.com/misabegovic/enola-guides/blob/main/guides/14-taha.md)** *(in private development)*: the agent harness built on tabula. It runs coding agents through the workflow I follow myself.
- **[tended](https://github.com/misabegovic/tended)**: a knowledge base your coding agent maintains for you, a markdown wiki it keeps true. `uvx tended init my-wiki`
- **[pi-brain](https://github.com/misabegovic/pi-brain)**: the same idea as a knowledge home for [pi](https://pi.dev), on npm. [muhamed.at](https://github.com/misabegovic/muhamed.github.io) runs on it.
- **[usput.ba](https://github.com/misabegovic/usput.ba)**: a travel guide to Bosnia and Herzegovina, with AI content grounded in real places. Rails 8, Hotwire, Solid Queue, Kamal.
- **[treasure_hunt](https://github.com/Ruby-Austria/treasure_hunt)**: a location-based treasure hunt built for RubyConf Austria 2026, open source for any conference.

#### Contributing

- **[enola](https://github.com/enola-labs/enola)**: pins a codebase's architecture as a baseline and grades each change against it, so a build fails only on what the change broke. Core contributor: I introduced its constraints, architectural rules a team declares and every change is checked against, along with fact providers and support for more languages and frameworks. I also maintain its Ruby gems, starting with [enola-rb](https://github.com/misabegovic/enola-rb) for Rails, and [enola-guides](https://github.com/misabegovic/enola-guides) for Rails, Ember, Python, TypeScript, Go and Rust.
