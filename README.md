### Hi, I'm Muhamed 👋

I'm a product engineer and tech lead living in Vienna. I like taking an idea all the way to something people actually use, and these days a lot of that means figuring out how teams can build well alongside AI. I've been writing Ruby since 2016, and I became a dad in 2025.

#### Projects

- **[usput.ba](https://github.com/misabegovic/usput.ba)**: a travel guide to Bosnia and Herzegovina, with AI content grounded in real places. Rails 8, Hotwire, Solid Queue, Kamal.
- **[pi-brain](https://github.com/misabegovic/pi-brain)**: a cloneable, agent-maintained knowledge base. [muhamed.at](https://github.com/misabegovic/muhamed.github.io) runs on a clone of it.
- **[brain](https://github.com/misabegovic/brain)**: a spec-driven engineering knowledge base that people and agents work from.
- **[enola](https://github.com/enola-labs/enola)**: architectural regression testing for AI-assisted development. Core contributor, and maintainer of the Ruby gems [enola-rb](https://github.com/misabegovic/enola-rb) and [enola-guides](https://github.com/misabegovic/enola-guides).
- **[treasure_hunt](https://github.com/Ruby-Austria/treasure_hunt)**: a location-based treasure hunt built for RubyConf Austria 2026, open source for any conference.
